# 독서토론으로 깊이 읽기 — 수업 시연

20명 학급의 「3구역, 1구역」(김혜진) 독서토론 수업 과정을 시연하는 데모입니다.

- **교사 화면 시연**: [index.html](https://leedongjin79.github.io/dokseo-toron-demo/) — 오른쪽 위 단계 버튼(1.밑줄 → 5.토론)으로 진행
- **학생 화면 시연**: [student.html](https://leedongjin79.github.io/dokseo-toron-demo/student.html)

수업 흐름: 밑줄 긋기 → 좋은 논제 배우기·논제 만들기 → 별·찬반 투표 → 결과(접전 배지·모둠 편성) → 입론·반론 카드와 팀 발표문.

※ 시연용 가상 데이터입니다. 본문 인용의 문단 번호는 시연용 가상 번호입니다.
